# 🆕 Portrait Viewport System

Unlike the original OBS Zoom scripts that zoom using the entire 1920x1080 desktop area, this modified version intelligently limits zoom calculations to the visible portrait viewport only.

## ✅ Benefits

- More focused framing
- Better vertical composition
- Less unnecessary horizontal movement
- Cleaner TikTok / Shorts camera behavior
- More professional-looking recordings
- Better viewer attention focus

| Setting | Recommended |

# ⚙️ Installation

## 1️⃣ Download the Script

Download the `.lua` file from this repository.

## 2️⃣ Open OBS Studio

Go to:

```text
Tools → Scripts
```

## 3️⃣ Add Script

- Click `+`
- Select the `.lua` script
- Choose your Display Capture source

## 4️⃣ Configure Hotkeys

Go to:

```text
Settings → Hotkeys
```

Assign:

- Toggle Zoom
- Toggle Mouse Follow

Done 🎉
